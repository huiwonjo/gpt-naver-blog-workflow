# GPT 네이버 블로그 워크플로우

ChatGPT로 **네이버 블로그 글을 만드는 과정**을 단계별로 진행하게 해 주는 설정 묶음입니다.

글감 후보 찾기 → 고르기 → 자료 조사 → 개요 → 원고 → 사실 검증 → (윤문) → 그림 → 태그 → **붙여넣기 화면**

이 묶음은 **진행 순서만** 정합니다. 블로그 주제, 카테고리, 말투, 글 구성, 그림 스타일, 태그 기준은 모두 쓰는 사람이
`지식파일/내_블로그_설정.md` 에서 정합니다. 비워 두면 첫 대화에서 GPT가 물어보고 채워 줍니다.

네이버에 넣는 것은 직접 합니다. GPT가 만든 붙여넣기 화면에서 버튼으로 복사해 붙여 넣고, 임시저장·발행은 직접 확인한 뒤 누릅니다.

## 받기

이 페이지 위쪽 **Code → Download ZIP** 으로 받아 압축을 풉니다.

## 설치 (10분)

### 방법 A. 나만의 GPT 만들기

1. ChatGPT 왼쪽 메뉴 **GPT** → **만들기** → **구성** 탭.
2. 이름과 설명을 자유롭게 적습니다.
3. **Instructions** 칸에 `1_GPT_지침.md` 의 '여기부터 복사' ~ '여기까지 복사' 사이를 붙여 넣습니다.
4. **대화 스타터** 칸에 `2_대화_시작_문구.md` 맨 위 4줄을 하나씩 넣습니다.
5. **지식** 에 `지식파일/` 안의 파일 10개를 모두 올립니다.
6. **기능**: 웹 검색 · 캔버스 · 코드 인터프리터(데이터 분석)를 켭니다. AI 그림을 쓸 거라면 이미지 생성도 켭니다.
7. 공개 범위는 **나만 보기**를 권합니다(설정 파일에 내 블로그 정보가 들어가므로).

### 방법 B. ChatGPT 프로젝트로 쓰기

1. 왼쪽 메뉴 **프로젝트** → 새 프로젝트.
2. 프로젝트 **지침**에 `1_GPT_지침.md` 의 복사 구간을 붙여 넣습니다.
3. 프로젝트 **파일**에 `지식파일/` 10개를 올립니다.
4. 프로젝트 안에서 새 대화를 열어 씁니다. 한 편에 한 대화를 권합니다.

계정 종류에 따라 GPT 만들기 메뉴나 올릴 수 있는 파일 수가 다를 수 있습니다. 파일 수가 모자라면 `01`~`08` 을 하나로 합쳐 올려도 됩니다.

## 처음 써 보기

1. **"처음이야. 내 블로그 설정부터 같이 채워줘"**
   → 질문에 답하면 GPT가 채운 `내_블로그_설정.md` 를 줍니다. 지식 파일의 설정을 그 파일로 바꿔 올리세요.
2. **"글감 후보 찾아줘"** → 후보를 고르면 원고 → 검증 → 그림 → 태그 순서로 진행합니다.
   GPT가 멈춰서 묻는 곳(후보 고르기, 개요, 검증 결과, 처음 쓰는 그림 스타일, 최종본)에서 답해 주세요.
3. 마지막에 받은 **붙여넣기 화면(.html)** 을 더블클릭해서 엽니다.
   [제목 복사] → 네이버 제목 칸, [본문 복사] → 본문 칸, 노란 표시 자리에 사진·소스코드·스티커, [태그 복사] → 태그 칸, **임시저장**.

미리 보고 싶다면 `예시/원고_예시.html` 을 열어 보세요.

## 이 워크플로우가 지키는 것

- **발행은 사람이.** GPT는 붙여넣기 화면까지만 만듭니다.
- **확인한 사실만.** 확인하지 못한 곳은 `[확인 필요: …]` 로 남고, 남아 있으면 붙여넣기 화면 맨 위에 경고가 뜹니다.
- **지어낸 경험 없음.** 직접 겪은 이야기가 필요한 자리는 빈칸으로 두고 직접 채웁니다.
- **검증은 따로.** 원고를 쓴 흐름과 나눠서 원문을 다시 열어 대조합니다.
- **검색량·조회수는 약속하지 않음.** 태그는 후보를 주고, 네이버 자동완성으로 직접 확인하는 방법을 안내합니다.

## 그래프에 한글을 쓰려면

ChatGPT 작업 공간에는 한글 글꼴이 없어 그래프 글자가 네모로 깨집니다.
[Noto Sans KR](https://fonts.google.com/noto/specimen/Noto+Sans+KR) 같은 한글 글꼴 `.ttf` 파일 하나를 지식 파일에 함께 올려 두세요.

## 변환 도구를 내 PC에서 돌리려면 (선택)

`원고_변환.py` 는 파이썬만 있으면 됩니다(추가 설치 없음).

```
python 지식파일/원고_변환.py 예시/원고_예시.md
python 지식파일/원고_변환.py 내원고.md --always-tags "#태그1 #태그2" --accent "#2563eb"
```

원고와 같은 폴더에 `.html` 이 만들어집니다.
