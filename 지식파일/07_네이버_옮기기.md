# 07. 네이버로 옮기기

GPT는 네이버에 로그인하거나 글을 올리지 않는다. **붙여넣기 화면(.html)** 을 만들어 주고, 사용자가 복사 버튼 → 붙여넣기로 옮긴다.
임시저장·발행은 사용자가 한다.

## 1. GPT: 붙여넣기 화면 만들기

1. 최종 원고를 `/mnt/data/원고이름.md` 로 저장한다.
2. 실행:
   ```
   python /mnt/data/원고_변환.py /mnt/data/원고이름.md
   ```
   설정 파일에 값이 있으면 덧붙인다:
   - `--always-tags "#태그 #태그"` : 모든 글 공통 태그
   - `--accent "#색코드"` : `==강조 구절==` 색 (없으면 굵게만)
3. 출력에 `확인 필요:` 줄이 있으면 먼저 원고를 고친다([확인 필요] 남음, 태그 30개 초과, 닫히지 않은 코드 칸).
4. 만들어진 `원고이름.html` 을 내려받기 링크로 준다.
   `/mnt/data/원고_변환.py` 가 없으면 사용자에게 원고_변환.py 파일을 대화에 올려 달라고 한다.

## 2. 사용자: 네이버에 넣기 (붙여넣기 화면 맨 위에도 같은 순서가 있다)

1. 내려받은 .html 을 더블클릭해 크롬·엣지로 연다.
2. 네이버 블로그 → 글쓰기.
3. **제목 복사** → 제목 칸에 Ctrl+V.
4. 본문 칸 클릭 → **본문 복사** → Ctrl+V. 글자 크기·굵게·색이 함께 들어간다.
5. 노란 표시 줄을 위에서부터 채운다:
   - `[사진 n …]` → 그 줄에서 사진 올리기, 노란 줄 지우기. **첫 사진이 대표 사진.**
   - `[소스코드 n 넣기]` → 붙여넣기 화면의 '소스코드 n' **복사** → 에디터의 '소스코드' 버튼으로 칸을 만들어 붙여넣기.
   - `[스티커 넣기]` → 스티커 고르기.
6. 발행 설정에서 카테고리를 고르고 **태그 복사** 한 것을 태그 칸에 붙인다. 한 덩어리로 들어가면 쉼표 자리에서 Enter 로 나눈다.
7. **임시저장**. 발행은 화면을 다 확인한 뒤 직접.

## 3. 넣은 뒤 확인

- 소제목 다음 줄 글씨가 커지거나 회색으로 번지지 않았는가 → 번진 줄만 선택해 보통 글씨로
- 사진 순서·위치, 남은 노란 표시 줄
- 링크, 카테고리, 태그 개수
- 모바일 미리보기

## 4. 에디터에서 직접 고쳤다면

고친 글 전체를 복사해 GPT에 붙여 준다. GPT는 원고를 같은 내용으로 맞추고, 바뀐 패턴을 '내가 고친 글에서 배운 규칙'으로 정리해 준다.

## 한계

- 사진·소스코드·스티커는 붙여넣기로 옮겨지지 않아 손으로 넣는다.
- 네이버 에디터가 바뀌면 일부 서식이 다르게 들어갈 수 있다 → 3번으로 확인한다.
