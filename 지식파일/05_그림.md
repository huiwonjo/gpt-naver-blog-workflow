# 05. 그림

그림의 종류·스타일·색은 모두 사용자가 정한다(설정 파일 '그림' 칸). GPT는 정해진 방식대로 만들거나 준비만 돕는다.
설정이 비어 있으면 이 단계에서 아래 선택지를 보여 주고 고르게 한다.

## 방식별 진행

| 설정의 그림 방식 | GPT가 하는 일 |
|---|---|
| **없음** | 원고에 사진 자리를 넣지 않는다 |
| **내 사진** | 사용자가 올린 사진을 보고 넣을 순서와 위치를 제안한다. 사진 속 개인정보(다른 사람 얼굴, 차량 번호, 영수증 카드번호, 위치 정보)를 사진마다 알려 준다. 사진은 고치지 않는다 |
| **AI 이미지 생성** | 설정의 스타일 설명으로 이미지를 만든다(아래 '이미지 생성') |
| **그래프** | 코드 인터프리터로 데이터 그래프를 만든다(아래 '그래프') |
| **내 템플릿** | 사용자가 올린 템플릿(HTML·이미지·캔바 등)에 들어갈 글자만 채워 준다. 디자인은 바꾸지 않는다 |
| **매번 물어봄** | 글마다 위 방식 중 무엇으로 할지 묻는다 |

공통:
- 그림에 넣는 숫자는 검증을 마친 값만.
- 만든 그림은 열어서 글자 오타·잘림·겹침을 확인한다.
- 처음 쓰는 스타일이면 원고에 넣기 전에 보여 주고 확인받는다.
- 파일 이름은 원고의 `![…](images/파일이름.png)` 와 맞춘다.

## 이미지 생성

프롬프트는 설정의 스타일 설명을 그대로 옮겨 만든다. 설정이 비어 있으면 아래 틀의 빈칸을 사용자에게 묻는다.

```
블로그 {대표 사진 / 본문 그림}, 비율 {1:1 / 가로형}.
주제: {이 글의 주제 한 줄}. 보여 줄 것: {사물·장면}.
들어갈 글자: "{정확한 글자}" — 이 글자 외에는 넣지 않음. (글자 없음이면 이 줄 삭제)
스타일: {설정의 스타일 설명 — 색, 분위기, 사진풍/일러스트 등}.
넣지 않을 것: {설정의 금지 요소}, 실존 인물 얼굴, 기관·브랜드 로고.
```

- 그림 속 한글은 틀리게 나오는 일이 잦다. 글자를 **한 자씩** 확인하고, 틀리면 다시 만들거나 글자 없이 만든 뒤 사용자가 편집 도구로 넣도록 권한다.
- 네이버의 'AI 활용' 표시를 할지는 사용자가 정한다(설정 파일).

## 그래프

- **ChatGPT 작업 공간에는 한글 글꼴이 없어 그래프 글자가 네모(□)로 깨진다.**
  사용자가 한글 글꼴 파일(.ttf, 예: Google Fonts 의 Noto Sans KR)을 지식 파일이나 대화에 올려 두면 아래처럼 쓴다.

```python
import matplotlib.pyplot as plt
from matplotlib import font_manager
FONT = "/mnt/data/NotoSansKR-Regular.ttf"          # 올린 파일 이름으로
font_manager.fontManager.addfont(FONT)
plt.rcParams["font.family"] = font_manager.FontProperties(fname=FONT).get_name()
plt.rcParams["axes.unicode_minus"] = False
```

- 색·글자 크기·제목 방식은 설정의 그림 칸을 따른다. 설정이 없으면 기본 모양으로 그리고 "색을 정하시면 맞춥니다"라고 알린다.
- 저장: `fig.savefig("/mnt/data/파일이름.png", dpi=200, bbox_inches="tight")` → 내려받기 링크.
