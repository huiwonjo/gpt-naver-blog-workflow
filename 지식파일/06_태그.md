# 06. 태그

GPT는 네이버 검색창 자동완성이나 데이터랩을 직접 열 수 없다. 그래서 **GPT가 후보를 만들고, 사용자가 확인**한다.
검색량 숫자를 지어내지 않고, 조회수가 늘어난다고 약속하지 않는다.

태그 수·순서 기준·공통 태그는 설정 파일을 따른다. 네이버 태그는 한 글에 **30개까지**다.

## 1. 후보 만들기

설정의 태그 수보다 넉넉하게, 묶음으로 나눠 보여 준다.

| 묶음 | 내용 |
|---|---|
| 핵심어 | 글의 주제어와 붙여 쓴 변형 |
| 독자가 묻는 말 | 주제어 + 조건·방법·기간·비용 같은 말 |
| 함께 찾는 말 | 비슷한 주제, 비교 대상 |
| 넓은 말 | 분야 전체를 가리키는 말 |
| 내 블로그 | 설정의 공통 태그·연재 이름 |

- 네이버 태그는 띄어쓰기 없이 들어간다.
- 본문에 나오지 않는 인기 검색어는 넣지 않는다.

## 2. 사용자 확인 안내 (1~2분)

> 네이버 검색창에 아래 말을 하나씩 **입력만** 해 보세요(검색 버튼은 안 눌러도 돼요).
> 아래에 자동완성이 여러 개 뜨면 실제로 많이 찾는 말이고, 하나도 안 뜨면 찾는 사람이 거의 없는 말이에요.
> 뜬 자동완성 문구를 그대로 복사해 붙여 주시면 태그를 다시 골라 드릴게요.

입력해 볼 말은 핵심어 묶음에서 4~6개만.

## 3. (선택) 데이터랩 비교

1. 네이버 데이터랩(datalab.naver.com) → 검색어트렌드에 주제어를 5개까지 넣고 조회한다.
2. 결과는 **그 조회 안에서 가장 높은 지점이 100인 상대값**이라 다른 조회와 바로 비교할 수 없다.
   여러 번 조회할 때는 같은 기준어 하나를 매번 넣고 `환산값 = 값 × (첫 조회의 기준어 값 / 이번 조회의 기준어 값)` 으로 맞춘다.
3. 사용자가 결과를 붙여 주면 GPT가 환산표를 만든다.

## 4. 고르기

- 자동완성이 하나도 안 뜬 말은 뺀다.
- 순서는 설정을 따른다. 정한 게 없으면 '많이 찾음 × 글과 관련 깊음' 순.
- 원고 마지막 줄에 `#태그 #태그 …` 한 줄로 쓴다. 설정의 공통 태그는 변환 때 자동으로 붙으니 쓰지 않아도 된다.
