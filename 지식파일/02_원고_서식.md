# 02. 원고 서식

원고는 아래 문법으로만 쓴다. 이 문법이어야 `원고_변환.py` 가 네이버에 붙여 넣을 화면을 만들 수 있다.
무엇을 어떤 말투로 쓸지는 내_블로그_설정.md 를 따른다. 이 파일은 **모양**만 정한다.

## 맨 위 정보 (frontmatter)

```
---
제목: 글 제목
카테고리: 네이버에 만든 카테고리 이름
상태: 원고 (검증 전)
기준일: YYYY-MM-DD
출처: https://… , https://…
---
```

- 값은 **한 줄**로 쓴다. `제목:` 과 `카테고리:` 를 변환기가 읽는다. 나머지 칸은 기록용이라 더하거나 빼도 된다.

## 본문 문법

| 원고 | 네이버에서 |
|---|---|
| `## 소제목` | 빈 줄 + 19px 굵은 글씨 |
| `**굵게**` | 굵게 |
| `==강조 구절==` | 굵게 (설정에 강조색이 있으면 그 색) |
| `↳ 보충` | 13px 회색 줄 — 덧붙이는 설명을 한 칸 아래에 둘 때 |
| `> 인용` | 인용 칸 |
| `- 항목`, `1. 항목` | 목록 |
| `[글자](https://주소)` | 링크 |
| `![설명](images/파일.png)` | 사진 자리 (한 줄에 하나만). **맨 앞 사진이 대표 사진** |
| ` ```언어 ` … ` ``` ` | 소스코드 자리 |
| `{sticker}` | 스티커 자리 |
| 빈 줄 | 빈 줄 하나 |
| 마지막 줄 `#태그 #태그` | 태그 목록으로 빠짐 (본문에 안 들어감) |

## 네이버 에디터 때문에 피하는 것

- **표(`| |`)** 는 네이버에 깨져 들어간다 → 그림으로 만들거나 문단으로 풀어 쓴다.
- **목록 항목 안에서 줄 바꾸기** 는 항목을 둘로 쪼갠다 → 긴 항목은 `**제목 줄**` + `↳ 설명 줄` 문단으로.
- **소스코드를 본문에 그냥 붙이기** 는 줄바꿈이 뭉개진다 → 코드 칸(```)으로 쓰면 변환기가 따로 복사 버튼을 만든다.
- 확인하지 못한 내용은 `[확인 필요: 무엇]` 으로 남긴다. 변환기가 붙여넣기 화면 맨 위에 경고로 띄운다.
