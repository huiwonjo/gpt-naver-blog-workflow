# 04. 윤문 (설정에서 켰을 때만)

목표: 내용은 그대로 두고, 기계적으로 읽히는 문장만 자연스럽게 고친다. 말투의 기준은 설정 파일이다.
자동 점수 도구는 없다 — **점수나 변경률 숫자를 지어내 보고하지 않는다.** 바꾼 곳이 많으면 대표 예시 3개만 전/후로 보여 준다.

## 바꾸지 않는 것

- 고유명사, 숫자·날짜·단위·금액, 직접 인용, 설정의 고정 문구·서두·마무리
- 주장의 강도: "~해야 한다" ↔ "~한다", "~일 수 있다" ↔ 단정으로 바꾸지 않는다
- 원고 서식 기호(`==`, `↳`, `![…](…)`, `{sticker}`, 태그 줄)
- 글의 절반 가까이를 바꾸게 되면 멈추고 사용자에게 알린다

## 자주 보이는 기계적 문장

| 증상 | 고치는 법 |
|---|---|
| 같은 종결어미가 3문장 이상 연속 | 종결을 섞는다(설정의 말투 범위 안에서) |
| 같은 도입구 반복("~와 같습니다", "생각해 보세요") | 두 번까지만 |
| "시사하는 바가 크다", "주목할 만하다", "매우 중요하다" | 지우거나 구체적인 사실로 |
| "크게 세 가지로 나눌 수 있습니다", "다음과 같습니다" | 도입구 없이 바로 내용 |
| 혁신적·획기적·압도적 같은 과장어 | 숫자·사실로 |
| 문단마다 "결론적으로/따라서/요약하면" | 한 글에 한두 번 |
| 문단 첫머리 "또한/즉/나아가/아울러" 반복 | 절반쯤 덜기 |
| 번역투 "~에 대해", "~를 통해", "~에 있어서" 반복 | "~를", "~로", "~에서" |
| 피동 "~되어진다", "~에 의해 ~된다" | 능동으로 |
| "A가 아니라 B" 대구가 여러 번 | 한 번만 |
| 연결어미 뒤 쉼표("-고,", "-며,") | 쉼표 빼기 |
| 문장 길이가 모두 비슷함 | 짧은 문장과 긴 문장을 섞기(내용 추가 없이) |
| 따옴표 강조·이모지·불릿 남발 | 꼭 필요한 곳만 |

## 고친 뒤 점검

1. 숫자·이름·날짜·인용이 원고와 한 글자도 다르지 않은가
2. 원래 없던 비유·수사·경험담을 새로 넣지 않았는가
3. 존댓말·반말 등 말투 등급이 그대로인가
4. 설정의 말투 규칙과 고정 문구가 살아 있는가

어긋난 문장은 원래대로 되돌린다.
